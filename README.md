# Wabi plugin

Skills and the hosted MCP servers for [Wabi](https://getwabi.dev?ref=plugin),
the operating platform for WhatsApp Business by Meter, for Claude Code, Codex
and Cursor.

- `wabi`: orient in an organization, try the sandbox number, follow events.
- `wabi-setup`: connect the CLI, the MCP server or an API key.
- `wabi-connect`: connect your own WhatsApp Business Account and number.
- `wabi-messaging`: send messages, templates, Flows and bulk sends, follow delivery.
- `wabi-templates`: create, translate and get templates approved.
- `wabi-inbox`: work the inbox, contacts, segments and campaigns.
- `wabi-webhooks`: receive and verify signed events in your backend.
- `wabi-agents`: build, test and deploy an AI support agent.
- `wabi-audit`: audit conversations, agents and costs.
- `wabi-billing`: plans, usage, Meta's fees, spend budgets and upgrade links.

Install in Claude Code with `/plugin marketplace add MeterApp/wabi-plugins`,
then `/plugin install wabi@wabi`.

Building on Wabi from code instead? The TypeScript SDK is
[`@meterapp/wabi-sdk`](https://getwabi.dev/docs/sdk?ref=plugin) and the CLI is
`npx @meterapp/wabi`.
